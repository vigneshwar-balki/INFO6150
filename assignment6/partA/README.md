# Assignment 6 - Part A: Calculator with User Login

This folder contains the web application for Part A of Assignment 6. It includes a login page and a calculator page built with modern JavaScript and jQuery.

## Features

- **Login page** with validation for Northeastern email and password
- **Client-side authentication** with hardcoded users
- Session management using sessionStorage or localStorage (remember me)
- Animated success messages and redirects
- **Calculator page** that performs addition, subtraction, multiplication, and division
- Single arrow function handles all operations
- Input validation and error messages using jQuery
- Logout functionality with animation

## Technologies

- HTML5, CSS3
- JavaScript (ES6+)
- jQuery
- Bootstrap Material Design CDN

## Running the application

1. Open `assignment6/partA/login.html` in a browser.
2. Use one of the predefined user credentials (`alice@northeastern.edu` / `password123`) to log in.
3. After successful login, you will be redirected to `calculator.html`.

## Bonus

- Dark-mode styling with Bootstrap Material Design
- Responsive layout using Flexbox
